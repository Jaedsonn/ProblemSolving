# ProblemSolving

Repositório com soluções de problemas de programação competitiva e estrutura de dados/algoritmos, escritas em **C++**. As soluções estão organizadas em pastas por tópico/técnica, facilitando o estudo e a revisão de padrões de resolução.

## Estrutura do repositório

| Pasta | Tema | Nº de soluções |
|---|---|---|
| `binary_search/` | Busca binária | 2 |
| `bit_manipulation/` | Manipulação de bits | 2 |
| `breadth_first_search/` | Busca em largura (BFS) | 1 |
| `depth_first_search/` | Busca em profundidade (DFS) | 1 |
| `divs/` | Problemas de "divs" (rounds/competições, ex. Codeforces) | 1 |
| `dsu/` | Disjoint Set Union (Union-Find) | 2 |
| `dynamic_programming/` | Programação dinâmica | 7 |
| `graphs/` | Grafos (MST, Euler Tour, ordenação topológica, etc.) | 4 |
| `greedy_algorithms/` | Algoritmos gulosos | 14 |
| `hash_tables/` | Tabelas hash | 1 |
| `math/` | Matemática (números, paridade, etc.) | 6 |
| `recursion/` | Recursão | 5 |
| `sorting_algorithms/` | Algoritmos de ordenação | 2 |
| `strings/` | Manipulação de strings | 6 |

> Algumas pastas (`dsu/colonization`, `graphs/toposort`) contêm subpastas com casos de teste ou arquivos auxiliares usados por aquela solução específica.

##Objetivo

Este repositório serve como um caderno de estudos e prática de:

- Estruturas de dados (DSU, hash tables, grafos).
- Técnicas algorítmicas (busca binária, BFS/DFS, programação dinâmica, algoritmos gulosos, recursão).
- Resolução de problemas de matemática, ordenação e strings.

Ideal para quem está treinando para competições de programação (como Codeforces) ou revisando conceitos fundamentais de algoritmos em C++.
